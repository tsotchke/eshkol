- Governing rule (maintainer): **docs are the blueprint and are not walked back.** A doc claim that describes a real, intended capability the code does not yet have is corrected only in the sense of being made *honest about present attainment* — the claim itself stays as tracked, targeted work. A doc is only softened/deleted when it is factually wrong about the past, or when it contradicts itself or another doc (in which case we resolve to the measured truth and cite it).

Resolution classes:

- **(a) FALSE-HISTORY** — corrected: the doc asserted something shipped/was true that wasn't.
- **(b) BUILD ITEM** — kept: the doc describes a real intended capability; the gap is filed as tracked work with a target and, where practical, a ledger tie-in. Never deleted.
- **(c) STALE-CLOSED** — closed: the issue/limitation was fixed; the doc is updated with evidence.
- **(d) SELF-CONTRADICTION** — resolved: two docs (or two passages of one doc) disagreed; resolved to the measured truth, wrong side corrected, cited.
- **(e) COSMETIC** — corrected: a count/path/line-number/stage-count drifted; remeasured and corrected.

## Surface-count unification (task item 4)

Ground truth: `tests/coverage/language_surface.json` `counts` = `{builtins_total: 1040, special_forms: 116, ast_ops: 113, prelude: 16}`. The **coverage gate's own denominator** — `tests/coverage/coverage_policy.json` `baseline_surface_total` and `tests/coverage/execution_deficit.json` `surface_total` — is **1,106**, computed by `scripts/language_coverage.py` (`surface = {}` block, ~L629-638) as `builtins ∪ special_forms ∪ prelude`, keyed by name (so a name shared across categories counts once) with leading-underscore internal-only helpers excluded. 1,106 is therefore not a fourth competing number — it is the same manifest, deduplicated the way the gate that actually enforces it already deduplicates it, and it was already the number `tests/coverage/coverage_policy.json` requires 100% coverage against.

Every place the audit found a different number (1,091 in FEATURE_MATRIX/COMPILER_ROADMAP, 1,078 in `.icc/architecture-model.yaml`, 1,058 in ADR-0010 §2.1, "550+/39" in README) is corrected to state **1,106** (1,040 builtins + 116 special forms + 113 AST ops + 16 prelude, deduplicated), with a one-line methodology note pointing at `scripts/language_coverage.py` and `tests/coverage/coverage_policy.json`.
