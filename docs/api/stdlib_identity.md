### `resolve_artifact`

*Function* — line 171

```c
inline platform::ResolvedInstallArtifact resolve_artifact(
 const std::vector<platform::InstallSearchRoot>& roots,
 const std::string& leaf) { ... }
```

Resolve a precompiled stdlib artifact (`stdlib.bc` or `stdlib.o`) for the running compiler. Every loader and the driver resolve through this one function, so they all agree on which copy is this compiler's. A copy in a tier someone chose (env, `-L`, beside the compiler, the working tree) is returned as found and the caller's identity validation accepts or refuses it. A copy that sits only in a system prefix and was produced by another build is not a candidate at all: the compiler proceeds as it does on a machine with no system install, loading the standard library from source.

**Parameters**

- `roots` — Ordered roots from platform::install_library_roots().
- `leaf` — `"stdlib.bc"` or `"stdlib.o"`.
