### `eshkol_add_stdlib_identity`

*Function* — line 49

```c
int eshkol_add_stdlib_identity(LLVMModuleRef module, const char* symbol);
```

Add an external artifact-identity global to a compiler-owned module.

**Parameters**

- `module` — Live module returned by an Eshkol library IR generator.
- `symbol` — Nonempty global identity name to embed in the module.

**Returns**

0 on success, -1 for invalid/unowned modules or a name collision. The stdlib build calls this before emitting its object and bitcode. The marker records the build's identity; it does not authenticate source input.
