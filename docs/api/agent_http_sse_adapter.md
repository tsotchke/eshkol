# `eshkol/agent_http_sse_adapter.h`

Accepted-HTTP-connection ownership adapter for server-side SSE. Transfers one accepted loopback HTTP/1.1 client connection from agent_http_server.c onto an explicit-loop resource lease from inc/eshkol/core/resource_lease.h. The HTTP server keeps its listener and complete-response path for subsequent connections; the adapter owns write-watch registration/removal on the caller's loop and single-close teardown via the shared cleanup-ticket contract.
