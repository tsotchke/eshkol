# `eshkol/platform/audio.h`

Real-time audio with callback-based I/O (ADR-0053; interface of docs/future/MULTIMEDIA_SYSTEM_ARCHITECTURE.md section 8.3). Backends: null (a clock-driven real-time thread with no device; always present), ALSA (libasound loaded at run time), CoreAudio (AudioToolbox loaded at run time). Real-time contract. The backend's audio thread calls the device callback once per period with `frames` interleaved frames in the configured format. The callback must not block, allocate or take locks. When no callback is given the device runs in queue mode: the built-in callback moves frames between the device and a lock-free single-producer/single-consumer ring. Output underruns (the ring had fewer frames than the period) are filled with silence and counted; input overruns (the ring was full) drop the newest frames and are counted. Every counter is read with atomic loads, so eshkol_audio_get_stats() is safe while the stream runs. Copyright (C) tsotchke SPDX-License-Identifier: MIT
