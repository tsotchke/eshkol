# `eshkol/platform/platform.h`

Eshkol platform layer: one C ABI for windows, events, real-time audio and MIDI across operating systems (ADR-0053). Every native backend (X11, Cocoa, ALSA, CoreAudio, ALSA sequencer, CoreMIDI) is bound at run time with the system dynamic loader, so a program that never opens a window or device acquires no link-time or load-time dependency, and a binary built on one host runs on a host without those libraries. Each subsystem also has a headless backend (offscreen display, null audio clock, MIDI loopback) that exercises the same public paths and is what the test suites run against. Backend selection per subsystem: ESHKOL_PLATFORM_DISPLAY = auto | offscreen | x11 | cocoa ESHKOL_PLATFORM_AUDIO = auto | null | alsa | coreaudio ESHKOL_PLATFORM_MIDI = auto | loopback | alsa | coremidi `auto` (the default) selects the native backend whose system library loads and otherwise the headless backend. An explicitly named backend that is not available is reported as ESHKOL_PLATFORM_EUNAVAILABLE; it never silently falls back. Copyright (C) tsotchke SPDX-License-Identifier: MIT
