# `eshkol/platform/window.h`

Cross-platform windows with a CPU pixel surface and an event queue (ADR-0053; interface of docs/future/MULTIMEDIA_SYSTEM_ARCHITECTURE.md section 8.2). Backends: offscreen (always), X11 (Linux/BSD, libX11 loaded at run time), Cocoa (macOS, AppKit loaded at run time). Every window owns an XRGB8888 surface; eshkol_window_present() copies it to the display. Each window has its own bounded, thread-safe event queue: poll/wait pump the backend, then pop. eshkol_window_push_event() may be called from any thread. Cocoa requires every window call to come from the process main thread. Copyright (C) tsotchke SPDX-License-Identifier: MIT
