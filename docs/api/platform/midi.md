# `eshkol/platform/midi.h`

MIDI 1.0 input/output (ADR-0053). Backends: loopback (in-process; always present), ALSA sequencer (libasound loaded at run time), CoreMIDI (loaded at run time). Addressing is by endpoint name on every backend: - an output port publishes a virtual source called `name` that other applications and Eshkol input ports can connect to; - an input port connects to the source called `name` (exact match, otherwise the first source whose name contains it). Messages are complete MIDI 1.0 messages: a status byte with its data bytes, or a SysEx F0 ... F7 block (running status is expanded by the receiver). Received messages pass from the backend thread to the reader through a lock-free single-producer/single-consumer ring with arrival timestamps (eshkol_platform_time_us()).
