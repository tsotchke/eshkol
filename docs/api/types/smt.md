# `eshkol/types/smt.h`

Built-in decision procedure for refinement-type verification conditions (ADR-0044). The procedure is self-contained: it needs no external solver and runs on every platform Eshkol builds on. It decides quantifier-free formulas over - linear integer arithmetic (Presburger, by the Omega test), - linear rational arithmetic (exact general simplex over Q, with strict bounds as delta-rationals; Fourier-Motzkin projection when integer and rational variables are mixed), - uninterpreted functions with equality (congruence closure), combined by a DPLL(T) search with delayed theory combination: every equality between variables shared by the arithmetic and the equality theories is a Boolean decision, so both theories agree on one arrangement (Nelson-Oppen for stably infinite theories). Numbers are exact. Integer wraps Eshkol's arbitrary-precision bignum (lib/core/bignum.cpp) with an int64 fast path; Rational is a normalised pair of Integers. Nothing is rounded anywhere in the procedure. The answer is three-valued. Unsat is a proof (relative to the procedure). Sat carries a model that has been re-evaluated against the original formula with the exact semantics of every interpreted symbol; a model that fails that evaluation (possible only when a nonlinear product was over-approximated as an uninterpreted function) degrades to Unknown. Unknown is also the answer when the deterministic step budget runs out. Unknown never counts as success. An optional z3 backend (SMT-LIB2 over a pipe) is compiled when the build option ESHKOL_REFINEMENT_Z3 is ON; makeZ3Solver() returns nullptr otherwise.

Decide a conjunction of linear constraints. `is_int[i]` marks integer variables.
