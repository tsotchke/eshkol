# `eshkol/types/hott_forms.h`

The HoTT forms of Eshkol source, handed to the cubical kernel (ADR-0043). (hott decl ...) declarations checked by the kernel at compile time; no runtime code; (hott-eval term) the kernel normalizes term; the form is replaced by the normal form as a quoted datum, so the program sees the computed value (both native engines and the bytecode VM). A rejected form is a compile-time error in every mode: a proof the kernel does not accept is not a proof.
