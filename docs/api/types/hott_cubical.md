# `eshkol/types/hott_cubical.h`

The cubical kernel of Eshkol's HoTT layer (ADR-0043). A dependent type theory with a De Morgan interval, path types, Kan operations (transp and hcomp), Glue types, univalence and higher inductive types, in the presentation of Cohen-Coquand-Huber-Mortberg (CCHM 2018), Coquand-Huber-Mortberg on higher inductive types (CHM 2018) and Cubical Agda (Vezzosi-Mortberg-Abel 2021). Every construction computes: transport along a univalence path applies the equivalence, the circle's eliminator computes on `loop` and on compositions of loops, and closed terms of inductive types normalize to constructors (canonicity). The kernel reads S-expressions. In Eshkol source they appear inside the `(hott decl...)` and `(hott-eval term)` forms; the front end hands the reader datum of those forms to this kernel. The surface language is documented in docs/reference/language/hott.md and docs/guide/HOTT.md.
