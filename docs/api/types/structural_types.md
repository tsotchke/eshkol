# `eshkol/types/structural_types.h`

Structural type terms of the Eshkol type system (ADR-0046). ADR-0004 calls for "hash-consed core terms with metavariables" beneath the packed TypeId layer. This header is that term language for the structural fragment: polymorphic types with metavariables and rigid variables, extensible records over kinded rows, arbitrary-rank `forall`, binary session protocols and their channel endpoints, one-shot (linear) arrows and multiple values. One solver serves all of them: - unification with occurs check, levels-based generalisation and level-based skolem escape (Kiselyov; Peyton Jones et al. 2007); - row unification by row rewriting (Remy; Leijen 2005) where every row variable carries the set of labels it must lack (Gaster and Jones 1996), which keeps rows duplicate-free and inference principal; - equi-recursive session protocols unified coinductively, with duality as an involution that also reaches unsolved protocol variables; - predicativity: a metavariable is only ever solved with a monotype. The same rows are the representation for effect rows (ADR-0045): an effect row is a RowExtend chain whose labels are effect names and whose fields are the effects' payload types; rowInclusion() is "fewer effects <: more". Nothing here knows about the AST; the checker in structural_checker.h walks programs and calls into this layer.
