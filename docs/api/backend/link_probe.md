### `eshkol_lld_on_path`

*Function* — line 16

```c
bool eshkol_lld_on_path();
```

True when `ld.lld` is on the PATH. Cached after the first call. AArch64 Linux links through lld when it is present (GNU ld 2.38 mishandles large user binaries). Passing -fuse-ld=lld on a host without lld fails every link with "invalid linker name", so callers probe first and fall back to the default linker, warning once.
