# `eshkol/backend/vm.h`

Public C ABI for the Eshkol bytecode VM. Lets external callers (e.g. qLLM) load an in-memory ESKB chunk, dispatch the bytecode through the interpreter, and tear the VM down without touching VM/EskbModule internals. Copyright (C) Tsotchke Corporation. MIT License.

*Function* — line 227

```c
void eshkol_vm_install_limits(uint64_t max_insn, int active, int enforce,
 void (*poll)(void));
```

Install the resolved limit configuration from a hosted entry point.

**Parameters**

- `max_insn` — Instruction ceiling (0 = unlimited).
- `active` — Non-zero if ESHKOL_VM_MAX_INSN was actually asked for.
- `enforce` — Non-zero to terminate rather than merely record a breach.
- `poll` — Cooperative timeout poll, or NULL for none.
