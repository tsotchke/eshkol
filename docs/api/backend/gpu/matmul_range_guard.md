Return 1 iff every entry in A (M x K) and B (K x N) is finite and every non-zero entry lies inside the safe single-precision product and K-term accumulation window [min_nonzero_abs, max_abs]. Exact zeros (+/-0.0) are always admitted. For plain f32 / fp24 routes pass df64_pair = 0 (min_nonzero_abs = 2^-60, guaranteeing |a*b| >= 2^-120 > FLT_MIN = 2^-126 with zero subnormal flush).
