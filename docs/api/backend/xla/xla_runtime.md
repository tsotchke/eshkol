### `XLARuntime::executeStableHLO`

*Function* — line 134

```c
ExecutionResult executeStableHLO(const std::string& module_text,
 const std::vector<BufferDescriptor>& inputs,
 std::vector<BufferDescriptor>& outputs);
```

Compile and execute StableHLO on the active PJRT device. Input and output descriptors must name host-resident, dense row-major f64 buffers (`on_device == false`, `element_size == sizeof(double)`). The PJRT executable stays inside this call, so it cannot be confused with the raw function pointer accepted by execute(). Returns a diagnostic and performs no host fallback when PJRT is inactive or compilation fails. Use the typed overload below for f32 and bf16 buffers.

### `XLARuntime::compileStableHLO`

*Function* — line 149

```c
std::unique_ptr<class StableHLOProgram> compileStableHLO(
 const std::string& module_text, std::string* diagnostic = nullptr);
```

Compile one explicitly reusable StableHLO program for this runtime's active PJRT session. On failure returns nullptr and stores a diagnostic. The program retains its session's client and plugin after this runtime is destroyed, until the program itself is released. Calls that overlap initialize(), or concurrent use of one runtime/program, require caller serialization.
