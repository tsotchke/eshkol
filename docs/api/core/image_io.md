# `eshkol/core/image_io.h`

Image I/O API — read/write PNG, JPEG, BMP as tensor data. Images are normalized doubles (0.0-1.0). Shapes: (H,W,C) for color, (H,W) for grayscale. The codecs are built into the runtime and behave identically on every platform; no external codec library is linked. WebP is Planned for v1.4.1. Memory ownership: returned arrays are arena-allocated from the Eshkol global arena. Callers must **not** free() them — the arena releases all allocations together at arena_reset() / arena_destroy() time. Copyright (C) Tsotchke Corporation. MIT License.

### `eshkol_image_read`

*Function* — line 35

```c
double* eshkol_image_read(const char* path, int* out_w, int* out_h, int* out_c);
```

Read image file → flat double array (normalized 0-1, row-major, HWC layout).

**Parameters**

- `path` — Path to image file: PNG (every colour type, bit depth and interlacing), JPEG (baseline, extended and progressive Huffman) or BMP; the format is detected from content
- `out_w` — Output: image width
- `out_h` — Output: image height
- `out_c` — Output: number of channels (3=RGB, or 4=RGBA when the file carries transparency; gray files are expanded to RGB)

**Returns**

Arena-allocated array of (w*h*c) doubles, or NULL on failure. Owned by the global arena — do NOT free().

Write tensor data to image file.

**Parameters**

- `path` — Output file path
- `data` — Flat double array (normalized 0-1)
- `w` — Image width
- `h` — Image height
- `channels` — Number of channels (1, 3, or 4)
- `format` — "png", "jpg"/"jpeg" (quality 90, alpha dropped) or "bmp" (NULL defaults to "png")

**Returns**

0 on success, -1 on failure
