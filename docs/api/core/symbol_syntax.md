*Function* — line 150

```c
static inline int eshkol_symbol_needs_bars(const char* name, size_t len) { ... }
```

Does `write` have to wrap this symbol name in vertical bars? Returns 1 when the name is not spelled by the bar-free R7RS 7.1.1 <identifier> productions, or when it is but some other Eshkol token would claim the bare spelling. See the file comment for the full rule.

**Parameters**

- `name` — Symbol name bytes; need not be NUL-terminated.
- `len` — Length of the name in bytes.
