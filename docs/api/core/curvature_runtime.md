# `eshkol/core/curvature_runtime.h`

Native (JIT/AOT) entry points of the ADR-0018 signed-curvature chart. These are the `extern` targets of `core.curvature` (lib/core/curvature.esk). Every function is a thin marshalling layer over the ONE f64 implementation in inc/eshkol/backend/riemannian_core.h, the same core the bytecode VM's geometry ops and the AD bridge call, so a native program and a VM program compute the same bits for the same inputs. Calling convention: points and vectors are f64 tensors (`eshkol_tensor_t*`, dtype F64); results are written into a caller-allocated output tensor of the documented length. Each function returns 0 on success and 1 on a refusal, whose reason eshkol_curvature_last_error() returns (thread-local, valid until the next call on the same thread).
