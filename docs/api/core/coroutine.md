### `eshkol_boundary_call_thunk`

*Function* — line 188

```c
int eshkol_boundary_call_thunk(const eshkol_tagged_value_t* thunk,
 eshkol_tagged_value_t* result,
 eshkol_boundary_raise_t* raised);
```

Call the nullary procedure `thunk` under an unwind boundary.

**Parameters**

- `thunk` — A callable tagged value.
- `result` — Receives the procedure's value when it returns normally.
- `raised` — Receives the recorded raise or transfer; `pending` is 0 when the procedure returned.

**Returns**

1 when the call was made; 0 when no thunk worker is registered (the compiled program has no procedures to call).
