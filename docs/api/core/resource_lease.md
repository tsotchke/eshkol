# `eshkol/core/resource_lease.h`

Shared lease and byte-counted outcome layer for hosted I/O resources. Every owned I/O resource kind (TCP/UDP sockets, TLS sessions, and the local IPC kinds that follow the same contract) is adopted into one process-wide registry from eshkol/core/handle.h. This header is the small common layer on top of it: - one acquire site per kind: eshkol_resource_adopt(); - one close site per kind: eshkol_resource_close(); - exclusive borrow/release around each operation; - one monotonic deadline per operation, shared across retries and phases; - readiness waits through the portable event loop (kqueue/epoll/IOCP), interruptible by eshkol_resource_cancel() from any thread; - one table of byte-counted outcome codes, identical for every kind. Identities are exact positive integers no larger than 2^53 - 1 and are never reused. Native bookkeeping lives outside movable arena regions.
