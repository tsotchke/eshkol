```c
int eshkol_linear_solve_portable(const double* matrix, const double* rhs,
 double* solution, int64_t n);
```

Solve one row-major square system with partial pivoting. Inputs are copied before elimination and `x` is written only on success. Pivots use exact-zero singularity detection, so nonzero tiny pivots are not rejected by a scale-dependent tolerance.

**Parameters**

- `matrix` — Row-major n-by-n finite coefficient matrix.
- `rhs` — Length-n finite right-hand side.
- `solution` — Caller-owned length-n output buffer.
- `n` — Positive system dimension.

**Returns**

One of the ESHKOL_LINEAR_SOLVE_PORTABLE_* status values.
