### `eshkol_net_open`

*Function* — line 18

```c
int64_t eshkol_net_open(const char *address, int32_t port, int32_t kind, int32_t timeout_ms);
```

Numeric IPv4/IPv6 sockets owned through the shared resource lease layer (eshkol/core/resource_lease.h): SOCKET-kind registry handles tagged listener, stream or datagram. Results use the ESHKOL_IO_* outcome codes: -1 system, -2 timeout/would-block, -3 unsupported platform, -4 invalid argument or stale/wrong-kind handle, -5 busy (another operation holds the handle), -6 cancelled (or closed during the operation), -7 peer reset, -8 datagram truncated, -9 connection refused. Positive handles are exact and never reused. Each operation waits on the calling thread's event loop under one monotonic deadline. No DNS lookup is performed. Kind 1 creates a listener, 2 connects a stream, 3 binds a datagram socket.
