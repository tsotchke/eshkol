```c
int64_t eshkol_net_open(const char *address, int32_t port, int32_t kind, int32_t timeout_ms);
```

Numeric IPv4/IPv6 sockets. Positive handles are never reused. Results: -1 system failure, -2 timeout/would-block, -3 unsupported platform, -4 invalid argument/handle. Close invalidates immediately; concurrent operations hold references until completion. No DNS lookup is performed. Kind 1 creates a listener, 2 connects a stream, 3 binds a datagram socket.
