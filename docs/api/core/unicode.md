### `eshkol_char_hex_literal`

*Function* — line 48

```c
static inline size_t eshkol_char_hex_literal(const char* data, size_t available,
 uint32_t* result, int* invalid) { ... }
```

R7RS 7.1.1 `#\x<hex scalar value>`, shared by both readers. `data` points just past `#\`; a NUL byte or `available` ends the input. When the spelling is `x`, one or more hexadecimal digits and then a delimiter (whitespace, `(`, `)`, `"`, `;`, `|`) or the end, returns the bytes it occupies and stores the scalar in *`result,` or sets *`invalid` when the digits name a surrogate or a value above U+10FFFF. Any other spelling -- `#\x` alone, `#\xylophone` -- returns 0 and is not a hex character.
