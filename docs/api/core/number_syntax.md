### `eshkol_number_syntax_parse`

```c
static inline eshkol_numsyn_status_t eshkol_number_syntax_parse(const char* text, size_t len,
 int default_radix,
 eshkol_numsyn_t* out) { ... }
```

Recognize an R7RS <number> and split it into canonical parts.

**Parameters**

- `text` — Token bytes (need not be NUL-terminated).
- `len` — Token length.
- `default_radix` — Radix when the token has no radix prefix (10, or the `string->number` radix argument: 2, 8, 10 or 16).
- `out` — Result; release with eshkol_number_syntax_free() when the status is ESHKOL_NUMSYN_OK (it is left empty otherwise).

**Returns**

ESHKOL_NUMSYN_OK, NOT_A_NUMBER for a token that is not number syntax (read it as an identifier), or a refusal for number syntax that has no value (see eshkol_numsyn_status_t).
