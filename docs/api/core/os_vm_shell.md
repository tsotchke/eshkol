### `eshkol_os_vm_eval_eskb`

*Function* — line 222

```c
eshkol_os_vm_status_t eshkol_os_vm_eval_eskb(eshkol_os_vm_shell_t* shell,
 const void* eskb_data,
 size_t eskb_size,
 const char* entry_name,
 eshkol_os_vm_result_t* out_result);
```

Decode, validate, and execute an in-memory ESKB v2 module inside the shell. If `entry_name` is NULL, executes function 0 (`main`); otherwise executes the named zero-argument function. Always rewinds the ephemeral OALR arena to zero live bytes before returning, regardless of success, fuel exhaustion, capability denial, or OOM.
