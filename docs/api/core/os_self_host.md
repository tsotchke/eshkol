
Compile Eshkol source directly into CRC32-verified ESKB v2 bytecode. All parser, symbol, and bytecode assembly tables are allocated exclusively inside the caller-supplied `workspace` buffer and rewound to zero before return. Supports integer/float/boolean/string literals, arithmetic (`+`, `-`, `*`, `/`, `modulo`, `abs`), comparisons (`=`, `<`, `<=`, `>`, `>=`), logic (`not`, `and`, `or`), `if`, `begin`, `let`, `let*`, named `let`, `define` functions with recursion and self-tail-call loops, pair primitives (`cons`, `car`, `cdr`, `null?`, `pair?`), and capability syscalls via `(os-syscall num cap arg0 ...)`.

**Parameters**

- `source` — Pointer to UTF-8 Eshkol source text.
- `source_len` — Byte length of `source`.
- `workspace` — Caller-supplied temporary scratch memory (zero malloc).
- `workspace_bytes` — Byte capacity of `workspace` (>= ESHKOL_OS_SH_MIN_WORKSPACE_BYTES).
- `out_buf` — Destination buffer receiving the serialized ESKB v2 image.
- `out_cap` — Byte capacity of `out_buf`.
- `out_result` — Optional output struct receiving status and telemetry.

**Returns**

ESHKOL_SH_OK on success, or an explicit error status.

Compile Eshkol source directly into a standalone static W^X ELF64 binary. Zero-LLVM, zero-assembler, zero-linker native code generator emitting a complete ET_EXEC ELF64 image for x86_64, AArch64, or RISC-V 64 with page-separated PT_LOAD segments (PF_R|PF_X .text and PF_R|PF_W .data, never PF_W|PF_X), zero PT_INTERP, zero PT_DYNAMIC, and an entry stub that evaluates the compiled program and exits via ESHKOL_SYS_TASK_EXIT (`syscall`, `svc #0`, or `ecall`).

**Parameters**

- `source` — Pointer to UTF-8 Eshkol source text.
- `source_len` — Byte length of `source`.
- `target` — Target 64-bit ISA (`ESHKOL_OS_TARGET_*`).
- `workspace` — Caller-supplied temporary scratch memory (zero malloc).
- `workspace_bytes` — Byte capacity of `workspace` (>= ESHKOL_OS_SH_MIN_WORKSPACE_BYTES).
- `out_buf` — Destination buffer receiving the ELF64 executable image.
- `out_cap` — Byte capacity of `out_buf`.
- `out_result` — Optional output struct receiving status and telemetry.

**Returns**

ESHKOL_SH_OK on success, or an explicit error status.
