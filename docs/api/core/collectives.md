Create a communicator for one rank in a world of `world_size` ranks. Rank 0 binds a TCP listener on `coord_host` : `coord_port` (pass port 0 for an ephemeral port, then query it with eshkol_coll_coord_port() or pass a pre-bound listener port in `out_port_cb` / separate handshake).
