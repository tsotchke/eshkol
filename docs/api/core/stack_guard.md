Whether the current thread has more than ESHKOL_STACK_SAFETY_MARGIN of stack left.

**Returns**

1 when there is headroom, or when the platform offers no way to ask (in which case the answer is conservatively yes); 0 when the thread is close enough to its bound that the caller must stop descending and report.
