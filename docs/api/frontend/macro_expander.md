### `MacroExpander`

*class* — line 40

```c
class MacroExpander
```

MacroExpander handles syntax-rules macro expansion. Usage: 1. Create a MacroExpander 2. Call expand() on the top-level AST 3. Use the returned AST (with macros expanded) for codegen The expander is recursive - expanded macros may themselves use macros.

### `MacroExpander::RenameEnv`

*class* — line 114

```c
class RenameEnv
```

Lexical value bindings in scope: source (possibly colored) name -> the unique name the binder was renamed to. Binding forms nest, so a form takes a mark() on entry and restore()s it on exit, which undoes exactly the names it bound. Entering a scope therefore costs nothing in proportion to the bindings already visible, and the environment stays linear in the number of binders however deeply they nest.
