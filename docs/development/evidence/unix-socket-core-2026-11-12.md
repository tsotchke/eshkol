# Unix socket core: Linux execution record

The initial core at `b4c26cde661f6995f9e055c04f084d476d065a1d` passed 65 selected Linux CTests, standalone shared/socket/PROCESS ASan/UBSan/leak checks, and a three-writer cold JIT cache check. The [historical manifest](unix-socket-core-2026-11-12.json) preserves source/artifact hashes and the original local-log hashes. Raw machine logs are retained locally and are not repository content. Summary commands use portable path placeholders.

The [review decisions](../../../notes/SOCKET_DESIGN_ANSWERS-2026-11-12.md) and [addendum](../../../notes/SOCKET_DESIGN_ADDENDUM-2026-11-10.md) describe the revised contract. Current revision qualification is in the [review revision record](unix-socket-review-revision-2026-11-12.md); historical results do not establish acceptance of later source changes.

Initial public acceptance used the production compiler, runtime and agent archive. Its test DSO interposed `connect` for every case on both platforms, forwarding calls to the real syscall except the labelled Darwin private-path pending controls. The revision separates this: the observation DSO has no interposer, Linux acceptance uses the real syscall, and a separate Darwin control DSO is loaded only for the three pending cases and the native control self-test. Darwin controls establish injected EAGAIN behavior, not an OS-pending connection.

The round trip checks request and reply bytes independently, including NULs. Large-payload acceptance transfers 16,777,253 bytes. The slow-peer fixture measures partial writes/would-block, and descriptor acceptance measures 1,000 cycles. Public byte comparisons inspect every byte directly. The revised driver takes the large-transfer time budget from a measured compiler-only pass, keeps its peer alive across compilation, verifies an atomically published saturated-backlog marker, and removes successful scratch directories. TMPDIR is honored when it fits the Unix pathname limit; a documented short-directory fallback handles longer prefixes.

The cache publishes completed objects from process-unique files, so concurrent writers never share one temporary name. One all-target parallel bootstrap configuration is outside this qualification. The historical scoped build and its selected tests are reported separately from that configuration. The prose surface checker has six count mismatches in five unchanged documents; generated backend API pages are intentionally deferred to integration.

MacOS kqueue is a separate native gate. MacOS public JIT/AOT, Windows socket/readiness execution, portable VM execution, the full repository test suite and release/package acceptance are not established by the Linux record. VM bridge refusal and unsupported-platform source controls do not count as platform execution.
