# `core.integer_linalg` — exact linear algebra over the integers

`(require core.integer_linalg)` provides linear algebra over Z, a principal
ideal domain: the Smith normal form with both transforms, integer kernels,
lattice membership and equality, and the cohomology of cochain complexes with
torsion and explicit generators. Rational matrices are handled by clearing
denominators row by row with integer products, so ranks and kernels over Q
come from the same engine. It is the linear algebra beneath
[`core.sheaf`](sheaf.md) and complements [`core.exact_linalg`](exact_linalg.md),
which works over fields.

Matrices are vectors of row vectors of exact numbers, as in
`core.exact_linalg`; build them with `vector`, not with `#(...)` literals
(which the reader turns into inexact tensors). A matrix with no rows cannot
record its width, so procedures that need a column count take it explicitly,
and `#f` stands for "no constraints" where a kernel is asked for.

| Procedure | Meaning |
|---|---|
| `(integer-matrix rows cols)` `(integer-identity-matrix n)` | zero and identity matrices |
| `integer-matrix-rows` `integer-matrix-cols` `integer-matrix-ref` `integer-matrix-set!` `integer-matrix-copy` | access |
| `integer-matrix-mul` `integer-matrix-vector` `integer-matrix-equal?` | products and equality |
| `integer-matrix-from-columns` `integer-matrix-column` `integer-matrix-vstack` `integer-matrix-hstack` | assembly (`vstack` returns `#f` when no block has rows) |
| `(smith-normal-form A)` | `(diag U V)` with `U A V = D`, `U`, `V` unimodular, `d_1 | d_2 | ...`; `A` is not modified |
| `smith-diagonal` `smith-left` `smith-right` | the parts of a Smith form |
| `integer-rank` `integer-invariant-factors` | rank and nonzero invariant factors |
| `(integer-kernel A ncols)` | a basis of the lattice `{x : A x = 0}` |
| `(integer-solve-in-basis snf ncols v)` | integer `y` with `B y = v` from the Smith form of `B`, or `#f` |
| `integer-in-column-span?` `integer-same-lattice?` | lattice membership and equality of column lattices |
| `(matrix-clear-denominators A)` | each row scaled to integers (same kernel, same rank over Q) |
| `rational-rank` `rational-kernel` `rational-solve` `rational-same-span?` | the Q versions; solutions are checked to be exact |
| `(cochain-cohomology dims Ds)` | `((k betti torsion) ...)` for `D_k : C^k -> C^{k+1}` |
| `(cochain-cohomology-generators dim-k D-prev D-k)` | `((order . cocycle) ...)`: order `0` for `Z`, `d > 1` for `Z/d` |

The Smith form follows the classical elimination (H. Cohen, *A Course in
Computational Algebraic Number Theory*, GTM 138, Algorithm 2.4.14). Entries
are fixnums or bignums; no step divides outside Z.

```scheme
(require stdlib)
(require core.integer_linalg)
(define A (vector (vector 2 4) (vector 6 8)))
(display (integer-invariant-factors A)) ;; => (2 4)
;; Z --2--> Z: H^0 = 0 and H^1 = Z/2, generated by a cocycle of order 2
(define D0 (vector (vector 2)))
(display (cochain-cohomology (list 1 1) (list D0 (integer-matrix 0 1)))) ;; => ((0 0 ()) (1 0 (2)))
(display (car (car (cochain-cohomology-generators 1 D0 (integer-matrix 0 1))))) ;; => 2
(display (rational-rank (vector (vector 1/2 1/3) (vector 1 2/3)))) ;; => 1
```
