Language Bindings — Reference

Eshkol embedded inside another language’s process, the opposite direction from Agent FFI (which calls out to native C from Eshkol). Each page covers one host language’s binding: what it wraps, how to build it, its API surface, and any lifetime/exactness caveats at the language boundary.

Cross-cutting notes

  • Direction matters: a binding here embeds Eshkol inside a host language’s process (Python calling in). Agent FFI is the other direction — Eshkol calling out to native C runtimes (agent.* modules). A feature request that sounds like “call X from Eshkol” belongs in the agent/FFI reference, not here.
  • Exactness at the boundary: a host language’s native numeric types (Python float, NumPy arrays) are not Eshkol’s exact rational/bignum tower. Converting a value across a binding may silently demote it — see each page’s own caveats before relying on a round-trip being exact.
