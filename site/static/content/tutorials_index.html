Running the Examples

Native compiler (fastest)

$ eshkol-run tutorial.esk -o tutorial && ./tutorial

Browser REPL (no install needed)

Visit eshkol.ai and paste code into the REPL.

Interactive REPL (local)

$ eshkol-repl
